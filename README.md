# COMP STUDIO

A modular visual compositor that runs in your browser:
**[comp.pantoine.com](https://comp.pantoine.com)**

Bring in an image or a video, wire it through effects, animate them, and
render the result. Nothing to install, and your pictures never leave your
machine.

https://github.com/user-attachments/assets/744cf0b5-6c35-4dbb-b4b0-60784ec5c7e9

## What's inside

- **80+ effects**: colour grading, CRT and tape artifacts, glitch, blur and
  lens optics, warps, time effects, generators.
- **Animate anything**: wire LFOs, noise, sequencers or envelopes into any
  setting, or let a picture drive it.
- **Groups and presets**: fold a chain into one card and save it for later.
- **Export** to PNG, JPG, GIF, MP4 or WebM.

## Getting started

1. Drop an image or video on the canvas, or paste one.
2. Press **Shift+A** to add an effect, and wire it in.
3. Add a **Viewer** to watch, or **Render** and **Exporter** to save a file.

The welcome tour and **Shortcuts & info** (top right) cover the rest.

## Run it locally

```bash
npm install
npm run dev
```
